# Tech Challenge - Fase 1

Projeto desenvolvido para a Pós Tech em Data Analytics da FIAP utilizando o dataset público de e-commerce da Olist.

## Objetivo

Analisar os dados da Olist buscando entender o desempenho da operação através de três pontos principais:

- Vendas e faturamento
- Tempo e prazo de entrega
- Satisfação dos clientes

Também foi realizada uma análise regional para identificar diferenças no desempenho logístico entre os estados.

## Análises realizadas

- GMV e evolução das vendas
- Ticket médio
- Tempo médio de entrega
- Entregas dentro e fora do prazo
- Relação entre atraso e avaliação do cliente
- Identificação de outliers
- Desempenho por estado

## Ferramentas

Python, Pandas, Matplotlib, Seaborn e Google Colab.
